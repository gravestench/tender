# 0005. Select Adyen ACH Direct Debit and giact for US consumer debits

Accepted for implementation on November 24, 2026. Merchant enablement is **BLOCKED**.

Blacktop can use one acquiring relationship for Visa, Mastercard and domestic USD bank debits. ACH reaches eligible accounts by routing number, including accounts at national banks, regional banks and credit unions. An individual debit still depends on merchant approval, accurate routing, the account type, authorization and the processor's validation decision. No bank-specific acceptance rate, pricing or production transaction has been established. [Adyen ACH Direct Debit](https://docs.adyen.com/payment-methods/ach-direct-debit/) · [Nacha routing guidance](https://www.nacha.org/news/ach-operations-bulletin-4-2024-importance-maintaining-date-routing-transit-numbers)

Select Adyen Checkout v72 Sessions and Adyen Web 6.45.2 for a one-time, personal checking or savings debit with online authorization under SEC code WEB. Select giact's consumer ecommerce option for account validation. Adyen requires a US registered business, an activated ACH payment method, a signed giact addendum and Support enablement. Adyen cautions merchants about the risk of one-off ACH payments. Funds can be returned after settlement. [Account validation and setup](https://docs.adyen.com/payment-methods/ach-direct-debit/verification-with-giact/) · [Payment types, mandates and returns](https://docs.adyen.com/payment-methods/ach-direct-debit/)

First-use Advanced-flow submission is prohibited. The pinned ACH Component exposes the holder, routing and account numbers to checkout JavaScript. The Sessions transport sends form data to the provider directly when the default submission path is used. The Component source renders fields and a pay button. Adyen requires the merchant to obtain a signed debit mandate. A real integration needs a compliant way to present and retain that mandate while keeping bank numbers out of Go. The protected sandbox probe exercises transport and test validation outcomes only. [Pinned component data](https://github.com/Adyen/adyen-web/blob/v6.45.2/packages/lib/src/components/Ach/Ach.tsx) · [Pinned form](https://github.com/Adyen/adyen-web/blob/v6.45.2/packages/lib/src/components/Ach/components/AchComponent.tsx) · [Pinned default session submission](https://github.com/Adyen/adyen-web/blob/v6.45.2/packages/lib/src/core/Services/sessions/make-payment.ts)

Enable the synthetic MOCK route for early host development. Keep SANDBOX and LIVE shopper actions unavailable pending merchant qualification, processor-approved mandate handling, an instrumented credentialed browser run and reconciliation against the merchant's report.
